**EduVerse AI** is an enterprise-grade, multi-tenant University and Institutional Resource Planning (ERP) platform built with native AI intelligence, 3D Digital Twin simulation, IoT telemetry, autonomous event-driven workflows, blockchain document verification, and DPDP / GDPR data governance.

---

## 🏛️ 13 Dedicated Role-Based Dashboards

EduVerse enforces strict role isolation with granular capabilities and interactive view switching:

1. **👑 Super Admin HQ (`/dashboard/super_admin`)**: Global governance, multi-tenant institutions, AI firewall, SIEM cybersecurity, system audit trails, and platform telemetry.
2. **🏛️ Campus Administrator (`/dashboard/admin`)**: Institutional operations, 3D digital campus, accreditation & OBE matrix, finance, admissions, health clinic, and physical assets.
3. **🛡️ Cyber Security Officer (`/dashboard/cybersecurity`)**: SIEM SOC operations, AI prompt injection firewall, cryptographic key rotation, and forensic audit timeline.
4. **💰 Finance Officer (`/dashboard/finance_officer`)**: Fee tier management, automated ledger reconciliation, purchase requisitions (PR/PO), and refund authorization.
5. **👥 HR Manager (`/dashboard/hr`)**: Faculty/staff directory, bio-metric attendance tracking, leave approval workflows, and payroll integration.
6. **💼 Placement Officer (`/dashboard/placement`)**: AI skill radar matching, recruiter job portal, hackathons, and student verified public portfolios.
7. **🚌 Transport Manager (`/dashboard/transport_manager`)**: Live GPS fleet telematics, bus route congestion tracking, student commuters, and vehicle maintenance.
8. **📚 Librarian (`/dashboard/librarian`)**: Digital book catalog, RFID inventory management, overdue fines, and e-learning resources.
9. **🛎️ Receptionist (`/dashboard/receptionist`)**: Digital visitor passes, gate QR scan verifications, and general inquiries desk.
10. **👨‍🏫 Faculty / Teacher (`/dashboard/teacher`)**: LMS video classroom, lesson planner, attendance register, exam grading, AI student risk alerts, and research grant tracker.
11. **🎓 Student (`/dashboard/student`)**: Course syllabus, AI tutor, timetable, grades, blockchain credential vault, smart mess QR tokens, gamification XP & leaderboard.
12. **👨‍👧 Parent (`/dashboard/parent`)**: Ward real-time attendance, grades, fee payment portal, mess nutrition logs, and live bus GPS tracking.
13. **👔 Staff / Employee (`/dashboard/employee`)**: Employee self-service, leave requests, attendance logs, and internal chat.

## 🛠️ Technology Stack

### Frontend
- **Framework**: React 19 + Vite 8
- **Routing**: React Router DOM v7 (with lazy-loaded route code splitting)
- **Styling**: Tailwind CSS, Vanilla CSS custom design system, Glassmorphism, CSS Variables
- **Animations**: Framer Motion
- **Icons**: React Icons (FontAwesome 5 & 6)
- **Real-Time**: Socket.io Client
- **Notifications**: React Hot Toast

### Backend
- **Runtime**: Node.js v20+ with TypeScript
- **Framework**: Express.js
- **Database**: MongoDB with Mongoose ODM
- **Authentication**: JWT (JSON Web Tokens) with HTTP-only cookies, Bcrypt password hashing
- **Real-Time Gateway**: Socket.io WebSockets
- **Architecture**: Modular Domain-Driven Controllers (`/src/modules/*`)

## ⚡ Getting Started Locally

### Prerequisites
- **Node.js**: v18+ (v20+ recommended)
- **MongoDB**: Local instance running on `mongodb://127.0.0.1:27017` or MongoDB Atlas URI

### 1. Clone & Configure Backend
```bash
cd backend
npm install

# Create environment file if not present
cp .env.example .env
```

Ensure `.env` contains:
```env
PORT=5000
MONGODB_URI=mongodb://127.0.0.1:27017/eduverse
JWT_SECRET=super_secret_jwt_key_2026
NODE_ENV=development
```

Start the backend server:
```bash
npm run dev
```
Backend runs at: `http://localhost:5000`

### 2. Configure & Run Frontend
```bash
cd ../frontend
npm install
npm run dev
```
Frontend runs at: `http://localhost:5173`
